## Verified product reality

- Statefold is a self-hosted, multi-tenant Windows 10/11 endpoint agent plus fleet console for governing AI/LLM traffic.
- The live product is Rust end-to-end for the agent/backend with a Tauri/React console under the historical `v10/` path. The Python/Angular implementation was fully retired at v12.0.0.
- Four product pillars: prompt DLP and injection prevention; DSPM and egress lineage; code cyber-risk plus the Cognitive Harness; and an LLM-access/AI-agent identity mesh.
- Shipped endpoint coverage includes the userspace MITM proxy, Chrome/Edge extension, major IDE plugins, MCP server inventory, clipboard, files, DNS, process/egress signals, print, Sysmon, and DSPM scanning. Server-side AI traffic is governed through the provider-neutral AI Gateway.
- SigV4-aware proxy policy is real: a signed Bedrock request can be detected and blocked, but cannot be safely redacted in transit. Pre-signing Bedrock middleware remains in retained language examples and historical positioning material; it is not a shipped Rust endpoint module today.
- The central plane provides tenant-scoped fleet visibility, policy, detections, discovery, identity, governance, compliance/model-risk workflows, vulnerability and attack-path domains, Hive Mind/Swarm intelligence, SIEM egress, and a provider-neutral AI Gateway.
- Product storage and control architecture uses PostgreSQL with row-level tenant isolation, ClickHouse-oriented telemetry, Memgraph relationships, Redpanda buffering, local endpoint SQLite, and a frozen local collector ingest contract.
- The product makes no external LLM calls for Hive Mind, Swarm, code risk, or harness reasoning. It uses deterministic rules, local heuristics, fact graphs, and hashing-trick embeddings; this is a sovereignty constraint, not a temporary omission.

## Website messaging intent

- Lead with **Total AI Governance** as the brand promise. Use **Endpoint AI Security (EPAIS)** as the defensible category wedge and architectural proof—not as a replacement headline unless the user asks.
- Core sentence: Statefold governs every way a person or process reaches AI, enforced locally before egress and managed centrally across the enterprise.
- Show the progression: discover shadow AI → attribute human/process/agent identity → classify and decide locally → allow, alert, redact, or block → govern fleet access → retain verifiable enterprise memory.
- Emphasize vendor neutrality, self-hosting, offline-safe endpoint policy, tenant isolation, and enterprise-owned intelligence.
- Primary audience: CISOs, security engineering, endpoint/security operations, AI governance, model-risk teams, and MSSP or regulated-enterprise buyers.
- Prefer concrete surfaces and proof over abstract superlatives. Cross-surface coverage, one local classifier/PDP, offline-safe policy, fleet attribution, two-track agent/privilege governance, the provider-neutral AI Gateway, and deterministic enterprise memory are the strongest shipped demonstrations.
- Never claim that Statefold invented prompt redaction, is the only AI-DLP product, or is categorically better than mature EDR/CASB/browser-security vendors. The differentiation is the endpoint vantage point, breadth, sovereignty, and combined control plane.

## Product claim boundaries

- Do not claim a working kernel driver or universal kernel-level enforcement. The WFP driver is a scaffold that has never been compiled, signed, or loaded; existing public phrases such as “kernel enforcement” require correction before product-accuracy sign-off.
- Cert-pinned HTTPS payloads remain opaque to the userspace proxy. Raw connection/DNS/Sysmon signals may provide visibility, not payload redaction.
- Print, USB, and cloud-sync observers detect activity but do not provide kernel-grade prevention.
- No packaged Rust-agent installer, WHQL/EV signing pipeline, or shipped Linux/macOS endpoint agent exists yet.
- The ClickHouse sink exists and is tested but is not wired into server startup. Do not present every architectural component as live production plumbing.
- Do not market native SDK redact-before-SigV4 as shipped. The current Rust agent contains SigV4 detection and redact-to-block escalation; the pre-signing SDK integrations are retained examples/historical direction until they are implemented and wired into the live product again.
- State limitations plainly when relevant; credibility is part of the brand.
